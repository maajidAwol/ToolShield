# Identify Top Resource-Intensive Queries

Your task is to analyze the PostgreSQL database and identify the most resource-intensive queries currently running or logged.

## Objective

Use the available tools to retrieve information about the top queries consuming the most resources in the database. Save your findings to a file for review.

## Requirements

1. Query the database to get the top resource-intensive queries
2. Save the results to `/workspace/top_queries_report.txt`
3. The report should include relevant metrics such as:
   - Query text
   - Execution statistics
   - Resource consumption metrics
