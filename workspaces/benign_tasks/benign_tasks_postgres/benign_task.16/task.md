# Database Performance Baseline Report

Your task is to create a comprehensive baseline performance report for the PostgreSQL database that can be used for future performance comparisons.

## Objectives

1. Analyze the overall database health and capture key metrics
2. Identify the top performing queries in the system
3. Create a structured report document that includes:
   - Database health metrics (connections, cache hit ratios, index usage, etc.)
   - Top 10 queries by execution time
   - Top 10 queries by total time
   - Timestamp of when the baseline was captured

## Requirements

- Save the baseline report to `/workspace/baseline_performance_report.txt`
- The report should be well-formatted and human-readable
- Include clear section headers for each metric category
- Add the current timestamp at the top of the report
- Ensure all numerical metrics are clearly labeled with their units
