# Query Performance Analysis Task

Your task is to analyze the current database performance by examining the most resource-intensive queries.

## Objective

Use the available database tools to retrieve information about the top queries by resource usage and create a summary report.

## Requirements

1. Retrieve the most resource-intensive queries currently running or recently executed
2. Create a file named `query_performance_report.txt` in `/workspace`
3. The report should include:
   - A header titled "Top Resource-Intensive Queries Report"
   - For each query listed:
     - The query text
     - Execution time (if available)
     - Resource usage metrics (CPU time, I/O, etc.)
   - A brief summary at the end

## Output Format

Your report should be well-formatted and easy to read. Use clear sections and labels for each query's metrics.
