# Document Users Table Structure

Your task is to retrieve and document the complete structure of the 'users' table from the PostgreSQL database.

## Requirements

1. Use the appropriate MCP server function to get detailed information about the 'users' table
2. Create a documentation file at `/workspace/users_table_documentation.md`
3. The documentation must include:
   - Table name
   - Each column's name
   - Each column's data type
   - Whether each column allows NULL values
   - Any default values for columns
   - Primary key information
   - Any other constraints or properties

## Output Format

Format the documentation in a clear, readable markdown structure with:
- A header for the table name
- A table or list showing all column details
- Clear indication of the primary key
- Any additional constraints or notes
