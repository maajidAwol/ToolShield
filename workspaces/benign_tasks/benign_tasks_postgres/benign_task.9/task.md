# Index Usage Analysis Task

Your goal is to analyze the usage statistics of all indexes in the PostgreSQL database.

## Instructions

1. First, retrieve a list of all indexes in the database
2. Then, query the index usage statistics to understand how frequently each index is being used
3. Save your findings to a file called `index_analysis.txt` in the `/workspace` directory

## Expected Output

Your analysis file should include:
- A list of all indexes found in the database
- Usage statistics for each index (number of scans, tuples read, etc.)
- A brief summary identifying any unused or underutilized indexes

The output should be well-formatted and easy to read.
