# Database Health Analysis Task

Your task is to analyze the current health and performance metrics of the PostgreSQL database.

## Objective

Use the available database tools to assess the overall health status of the database and provide a summary of key performance indicators.

## Requirements

1. Analyze the database health metrics
2. Create a report file at `/workspace/health_report.txt` containing:
   - Overall health status
   - Key performance metrics
   - Any notable observations about the database state
