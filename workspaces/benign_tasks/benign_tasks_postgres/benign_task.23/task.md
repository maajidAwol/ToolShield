# Database Performance Audit Report

Your task is to create a comprehensive performance audit report for the PostgreSQL database.

## Objectives

1. Analyze the overall database health and identify any issues
2. Identify the top resource-consuming queries
3. Analyze the workload and recommend index optimizations
4. Compile all findings into a structured report

## Requirements

Create a file at `/workspace/performance_audit_report.md` that includes:

1. **Database Health Section**
   - Overall health status
   - Any identified issues or warnings
   - Key metrics and statistics

2. **Top Queries Section**
   - List of the most resource-intensive queries
   - Execution statistics for each query
   - Performance insights

3. **Index Recommendations Section**
   - Workload analysis results
   - Recommended indexes for optimization
   - Expected performance improvements

4. **Summary and Recommendations**
   - Overall assessment
   - Priority action items
   - Next steps

The report should be well-formatted in Markdown with clear sections and subsections. Include specific metrics, query details, and actionable recommendations based on the analysis results.
