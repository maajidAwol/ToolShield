# Analyze Database Workload and Recommend Indexes

Your task is to analyze the current query workload patterns in the PostgreSQL database and recommend indexes to improve overall performance.

## Instructions

1. Use the `analyze_workload_indexes` function to review current query patterns
2. Generate a comprehensive index recommendation report
3. Save the report to `/workspace/index_recommendations.txt`

## Report Requirements

Your report must include:
- A summary of the workload analysis
- Specific index recommendations with table and column details
- Expected performance improvements for each recommendation
- Priority level for each recommended index (High/Medium/Low)
