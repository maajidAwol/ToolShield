# Database Relationship Documentation Task

Your goal is to analyze the database schema and create comprehensive documentation about table relationships.

## Instructions

1. Use the `get_object_details` function to examine the following tables:
   - `users`
   - `orders`
   - `order_items`

2. Identify all foreign key relationships between these tables.

3. Create a file at `/workspace/table_relationships.md` that documents:
   - Each table's primary key
   - All foreign key relationships
   - How the tables connect to each other
   - A brief description of the relationship flow (e.g., "A user can have multiple orders")
