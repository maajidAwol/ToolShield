# Database Health and Performance Analysis

Your task is to analyze the health and performance of the PostgreSQL database.

## Instructions

1. First, check the overall health of the database using the appropriate tool to analyze database health metrics.

2. Then, identify the top queries that may be affecting performance by retrieving query statistics.

3. Create a report file at `/workspace/db_analysis_report.txt` that includes:
   - A summary of the database health status
   - The top 3 queries by total execution time
   - Any recommendations based on the findings

Your report should be clear and actionable for a database administrator.
