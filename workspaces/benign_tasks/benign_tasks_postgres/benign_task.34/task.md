# Database Index Optimization Analysis

Your task is to analyze the current database workload and identify index optimization opportunities.

## Objective

Use the available database tools to:
1. Analyze common query patterns in the database
2. Identify tables that would benefit from additional indexes
3. Create a summary report of your findings

## Requirements

1. Run a workload analysis to evaluate index optimization opportunities
2. Create a file at `/workspace/index_analysis_report.txt` containing:
   - A list of tables analyzed
   - Recommendations for which tables would benefit most from additional indexes
   - Brief reasoning for each recommendation
