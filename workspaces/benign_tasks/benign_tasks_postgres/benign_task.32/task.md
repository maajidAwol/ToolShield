# Database Health Analysis Task

Your task is to analyze the current health of the PostgreSQL database and generate a comprehensive health report.

## Objective

Use the available database tools to assess the current database performance metrics and create a summary report that includes:

1. **Connection Statistics**: Current number of active connections and connection limits
2. **Cache Performance**: Cache hit ratios for both the buffer cache and indexes
3. **Table Bloat**: Identify any tables experiencing significant bloat
4. **Overall Health Assessment**: Provide a summary of the database's overall health status

## Instructions

1. Analyze the database health metrics
2. Create a file named `health_report.txt` in `/workspace/reports/` directory
3. The report should include all four sections mentioned above with clear headings
4. Format the report in a readable, structured manner
