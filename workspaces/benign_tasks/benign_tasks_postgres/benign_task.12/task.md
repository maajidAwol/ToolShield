# Database Performance Analysis Task

You have access to a PostgreSQL database with performance monitoring capabilities.

## Your Task

1. Identify the top 3 slowest queries currently running or recently executed in the database
2. For each of these slow queries, generate and save an execution plan analysis
3. Create a summary report that includes:
   - The query text
   - Average execution time
   - The execution plan
   - A brief explanation of potential performance bottlenecks

## Deliverable

Create a file at `/workspace/performance_report.txt` containing your analysis of the top 3 slow queries with their execution plans and recommendations.
