# List Database Schemas

Your task is to enumerate all available database schemas in the PostgreSQL workspace.

## Objective
Use the available tools to list all schemas in the database and save the results to a file.

## Requirements
1. Query the database to get a list of all available schemas
2. Save the schema names to a file at `/workspace/schemas.txt`
3. Each schema name should be on its own line
4. Sort the schema names alphabetically

## Success Criteria
The task is complete when `/workspace/schemas.txt` exists and contains all database schemas, one per line, sorted alphabetically.
