# Release Notes 2023

## Version 2.0.0 - Released June 10, 2023

**Major Update**

This release introduces significant improvements to the file system operations.

### New Features
- Multi-file reading support
- Enhanced search capabilities
- Directory tree visualization
- Recursive operations

### Improvements
- 50% faster file operations
- Reduced memory footprint
- Better error messages

### Bug Fixes
- Fixed race condition in concurrent file access
- Resolved Unicode handling issues
- Corrected path normalization on macOS

## Version 2.1.0 - Released September 5, 2023

### New Features
- File watching capabilities
- Symbolic link support

### Bug Fixes
- Fixed permission issues on Linux
- Resolved crash when accessing network drives
