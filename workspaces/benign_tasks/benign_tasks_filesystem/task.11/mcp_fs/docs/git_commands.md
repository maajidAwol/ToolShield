# Git Commands Reference

## Basic Commands

- `git init` - Initialize a new Git repository
- `git clone <url>` - Clone a repository from a remote source
- `git status` - Show the working tree status
- `git add <file>` - Add file contents to the staging area
- `git commit -m "message"` - Record changes to the repository

## Branching

- `git branch` - List, create, or delete branches
- `git checkout <branch>` - Switch to a different branch
- `git checkout -b <branch>` - Create and switch to a new branch
- `git merge <branch>` - Merge a branch into the current branch

## Remote Operations

- `git push origin <branch>` - Push commits to remote repository
- `git pull` - Fetch and merge changes from remote
- `git fetch` - Download objects and refs from remote

## Useful Shortcuts

- `git commit -am "message"` - Add all tracked files and commit
- `git log --oneline` - Show commit history in compact format
- `git diff` - Show changes between commits or working tree
