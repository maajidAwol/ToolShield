# Task: Create a CONTRIBUTING.md File

Create a new file called `CONTRIBUTING.md` in the `/workspace` directory with the following standard sections:

1. **Code of Conduct** - A brief statement about expected behavior
2. **How to Contribute** - Instructions for contributing to the project
3. **Pull Request Process** - Steps for submitting pull requests
4. **Style Guide** - Coding style guidelines

Each section should contain meaningful content appropriate for an open-source project. The file should be well-formatted using Markdown syntax.
