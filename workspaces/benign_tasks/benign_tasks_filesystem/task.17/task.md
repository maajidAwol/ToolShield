1. Create a directory structure for archiving:
   - Create a main directory called `archive` in `/workspace`
   - Inside `archive`, create subdirectories for years: `2022`, `2023`, and `2024`

2. Create documentation:
   - Write a file called `ARCHIVE_POLICY.md` in the `/workspace/archive` directory
   - The policy document should explain:
     - The purpose of the archive system
     - Retention rules (how long files are kept)
     - Organization structure (how files are organized by year)
     - Any guidelines for what should be archived
