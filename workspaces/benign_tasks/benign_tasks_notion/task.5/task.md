# Task: Add IT Troubleshooting Entry

Your goal is to add a new troubleshooting entry to the IT Troubleshooting Hub page in Notion.

## Instructions

1. Search for and locate the "IT Troubleshooting Hub" page in the Notion workspace
2. Once found, append a new troubleshooting entry to the page with the following information:
   - **Problem**: "Laptop won't connect to Wi-Fi after Windows update"
   - **Solution Steps**:
     1. Restart the laptop and router
     2. Run Windows Network Troubleshooter
     3. Update network adapter drivers from Device Manager
     4. Reset network settings using 'netsh winsock reset' command
     5. If issue persists, roll back the Windows update

3. Format the entry clearly with the problem as a heading and solution steps as a numbered list

Complete this task using the available Notion API functions.
