# Task: Create New Employee Onboarding Checklist

Navigate to the "Company In A Box" page in the Notion workspace and create a new child page titled "New Employee Onboarding Checklist". 

The new page should contain a checklist with the following items:
- Complete HR paperwork
- Set up company email account
- Review employee handbook
- Schedule orientation meeting
- Obtain building access badge

Each item should be formatted as a to-do block (checkbox).
