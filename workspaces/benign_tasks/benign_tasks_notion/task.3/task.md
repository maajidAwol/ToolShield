# Task: Mark Project Milestone Complete

You need to navigate to the Team Projects page in the Notion workspace and mark a project milestone as complete by adding a comment.

## Instructions:

1. Search for the "Team Projects" page in the Notion workspace
2. Retrieve the full details of the Team Projects page
3. Add a comment to the page with the following text: "Milestone: Q1 Planning Phase - Status: Complete. All deliverables have been reviewed and approved."

Your task is complete when the comment has been successfully added to the Team Projects page.
